# Zomato-Sales-Performance-Dashboard
The Zomato Sales Performance Dashboard is a comprehensive business intelligence solution designed to analyze and visualize sales, customer ratings, and operational metrics across various restaurants, cities, and states. Built using data visualization tools, this interactive dashboard transforms raw transactional data into actionable insights.


An interactive data analytics dashboard built to monitor, evaluate, and report comprehensive sales performance metrics for Zomato restaurant partners.

## 🚀 Project Overview
This project provides a centralized view of business operations, sales volumes, customer satisfaction, and geographical demand. It is designed for restaurant managers, business analysts, and decision-makers to identify sales drivers and seasonal purchasing patterns.

## 📌 Key Metrics
Executive Summary KPIs: Tracks core performance indicators including Total Sales (₹52.05M), Average Ratings (4.34), Average Order Value (₹268.41), Ratings Count (5.5M), and Total Orders (193.9K).   Trend Analysis: Visualizes performance fluctuations through dedicated Monthly Sales Trend (Jan–Aug), Daily Sales Trend (Sun–Sat), and Weekly Sales Trend (Weeks 1–35) charts.   Geographical & Segment Insights: Highlights top-performing locations via the Top 5 Cities by Sales ranking (including New Delhi, Mumbai, Lucknow, Hyderabad, and Bengaluru) alongside state-level and restaurant-level filters.   Product Preferences: Features a Total Sales by Food Type breakdown comparing Veg vs. Non-Veg sales distribution.   Interactive Filtering: Includes slicers and filter panes for Months, States, and specific Restaurants to enable dynamic, drill-down data exploration. 
* **Total Sales:** ₹52.05M

* **Average Order Value:** ₹268.41
